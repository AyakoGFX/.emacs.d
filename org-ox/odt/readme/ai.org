* Setup & Installation

There are two versions of =ox-odt=:
1. *Built-in ox-odt*: Comes bundled with stock Emacs/Org mode.
2. *Enhanced ox-odt*: Forked and maintained by the original author with additional features and bug fixes.

** Installing the Enhanced Version (Elpaca)
[[https://github.com/kjambunathan/org-mode-ox-odt#installation][Installation Manual]]

Add the following block to your Emacs configuration:

#+begin_src emacs-lisp
(elpaca (ox-odt :host github
                :repo "kjambunathan/org-mode-ox-odt"
                :files ("lisp/ox-odt.el"
                        "lisp/ox-ods.el"
                        "lisp/odt.el"
                        "etc"
                        "docs"
                        "contrib/odt/LibreOffice")))
#+end_src


* Useful Commands & Workflow

| Shortcut | Command / Function | Description |
|----------+--------------------+-------------|
| ~C-c C-e o o~ | =org-odt-export-to-odt= | Export current buffer to =.odt= and open it |
| ~C-c C-e o O~ | =org-odt-export-to-odt= | Export and convert directly to PDF/DOCX |

* ODT Specific Export Settings

Reference: [[https://orgmode.org/manual/ODT-specific-export-settings.html][ODT Specific Settings Manual]]

Header options inserted into the top of your document:

#+begin_src org
  ,#+TITLE: My Document Title
  ,#+SUBTITLE: Subtitle or Description
  ,#+AUTHOR: kishore
  ,#+KEYWORDS: emacs org-mode odt export
  ,#+OPTIONS: toc:t num:t H:6

  # ODT Directives
  ,#+ODT_PREFERRED_OUTPUT_FORMAT: pdf
  ,#+ODT_STYLES_FILE: "./template.ott"
  ,#+ODT_EXTRA_STYLES: ...
  ,#+ODT_EXTRA_IMAGES: ...
  ,#+ODT_EXTRA_AUTOMATIC_STYLES: ...
  ,#+ODT_MASTER_STYLES: ...
  ,#+ODT_CONTENT_TEMPLATE_FILE: ...
  ,#+ODT_AUTOMATIC_STYLES: ...
#+end_src

** Explanation of Core Options
- =toc:t= :: Generates a Table of Contents (=toc:nil= to disable).
- =num:t= :: Numbers section headings automatically (=num:nil= for unnumbered).
- =H:6= :: Sets headline export depth to 6. *Crucial:* By default, Org mode turns levels deeper than 3 into bullet lists. Setting =H:6= forces levels 1–6 to render as real headings.
- =#+ODT_PREFERRED_OUTPUT_FORMAT: pdf= :: Automatically invokes LibreOffice in the background to convert `.odt` into `pdf` (or `docx`, `doc`, `rtf`).

* Applying Custom Styles

Reference: [[https://orgmode.org/manual/Applying-custom-styles.html][Applying Custom Styles Manual]]

** 1. Using a LibreOffice Template (.ott)
The cleanest approach for document-wide custom styles:

#+begin_src org
  ,#+ODT_STYLES_FILE: "/path/to/example.ott"
#+end_src

** 2. Using Inline `odt_extra_styles`
You can define XML style blocks directly inside your Org document and apply them to elements.

*** Usage Examples:
