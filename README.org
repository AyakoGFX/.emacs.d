* the fill
| cmd             | key                          | Description                                           |
|-----------------+------------------------------+-------------------------------------------------------|
| set-fill-column | C-x f                        | Sets the width for the current buffer interactively.  |
| fill-region     | C-x f (then M-x fill-region) | Refills a selected block of text.                     |
| fill-paragraph  | M-q                          | Refills the current paragraph to fit the fill-column. |
** auto-fill-mode 
Once auto-fill-mode is enabled, 
you can manage existing text blocks manually with these commands:
#+begin_src emacs-lisp
(add-hook 'text-mode-hook 'auto-fill-mode)
(add-hook 'prog-mode-hook 'auto-fill-mode)
#+end_src

| Key   | Action                                              |
|-------+-----------------------------------------------------|
| ~n / p~ | Move to the next / previous node at the same level  |

| ~q~     | Quit Info mode                                      |

* Configure Emacs for LaTeX
Install all the latex pkgs
   #+begin_src sh
     sudo pacman -S texlive
   #+end_src

Next we need to tell Emacs how to handle LaTeX.
#+begin_src emacs-lisp
;; Force Org-mode to export with XeLaTeX
(setq org-latex-compiler "xelatex")

;; Set XeLaTeX as the build process (runs twice to resolve TOC and references)
(setq org-latex-pdf-process
      '("xelatex -shell-escape -interaction nonstopmode -output-directory %o %f"
        "xelatex -shell-escape -interaction nonstopmode -output-directory %o %f"))

(setq org-latex-listings 't)

(require 'ox-latex)

;; Custom Class Definition
(add-to-list 'org-latex-classes
             '("org-plain-latex"
               "\\documentclass{article}
               [NO-DEFAULT-PACKAGES]
               [PACKAGES]
               [EXTRA]"
               ("\\section{%s}" . "\\section*{%s}")
               ("\\subsection{%s}" . "\\subsection*{%s}")
               ("\\subsubsection{%s}" . "\\subsubsection*{%s}")
               ("\\paragraph{%s}" . "\\paragraph*{%s}")
               ("\\subparagraph{%s}" . "\\subparagraph*{%s}")))

(put 'upcase-region 'disabled nil)
#+end_src
